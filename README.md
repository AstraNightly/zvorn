# zvorn

a chess engine in one file.

full legal movement (castling, en passant, promotion), proper algebraic
notation with disambiguation, and an alpha-beta search with quiescence that
runs in a worker so the board never stutters. click a piece, click a square.

no tablebases, no openinig book, no libraries: just a board, a search,
and a small stubborn opinion about pawn structure.
